3-Minute Verification Protocols for Beta Testers

        
QueryGuard runs inside an ephemeral PostgreSQL 16 container inside your GitHub Actions runner. Zero PII, production rows, or query logs leave your infrastructure.

        
        
Test 1: Migration Lock Sentinel

        
Add CREATE INDEX idx_test_lock ON table(col); without CONCURRENTLY to your schema file. Verify that QueryGuard flags a SHARE lock and suggests the non-blocking concurrent replacement.


        
Test 2: Full Table Scan Detection

        
Add an unindexed lookup SELECT * FROM table WHERE unindexed_col = 'val'; to your queries file. Verify that QueryGuard executes zero-PII scaffolding, evaluates the sequential scan, and outputs a CREATE INDEX CONCURRENTLY fix.


        
Test 3: In-Place Comment Updates

        
Push a second commit to the PR adding CONCURRENTLY and the index. Verify that QueryGuard patches the existing comment in-place with a clean passing report.
